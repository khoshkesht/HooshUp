Style Guide ثابت فضاهای بازی
1) هویت کلی بصری

فضاها باید حس یک بازی ماجراجویی موبایلی مدرن را بدهند؛
نه دکوراسیون داخلی صرف، نه رندر معماری، نه تصویر خیلی کودکانه.

ویژگی اصلی:
Isometric 2.5D
Adventure Game Environment
Cozy, Clean, Modern
Stylized but believable
Game-first
Teen-friendly
Minimal but alive
2) قانون ثابت دوربین
زاویه دید: سه‌ربع از بالا
نوع دوربین: isometric 2.5D perspective
حس دوربین: شبیه محیط یک بازی ماجراجویی / simulation
تصویر باید کل قاب را با محیط و المان‌ها پر کند
فضا نباید مثل ماکت، دیوراما، cutaway dollhouse یا اتاق داخل قاب دیده شود
کناره‌های اضافی، دیوارهای بریده یا اتاق‌های مجاور نباید تمرکز را بگیرند
صحنه باید حس یک لوکیشن قابل تعامل را بدهد
جمله ثابت پیشنهادی:

نمای دوربین isometric 2.5D با زاویه three-quarter overhead، شبیه محیط یک بازی ماجراجویی موبایلی، به‌طوری‌که کل صحنه قاب را پر کند و محیط مثل یک game environment یکپارچه دیده شود، نه مثل اتاقی درون قاب یا دیوراما.

3) زبان طراحی محیط

فضاها باید:

مرتب و کنترل‌شده
مینیمال اما نه خالی
زیبا و دوست‌داشتنی اما نه بچگانه
مدرن و امروزی
قابل‌پذیرش برای نوجوان ایرانی امروز
دارای جزئیات کافی برای حس زندگی ولی بدون شلوغی بصری
در عمل:
اشیاء کم اما درست انتخاب‌شده
سطوح تمیز
چیدمان طبیعی
دکور محدود و هدفمند
بدون تزئینات زیاد و شلوغ
4) پالت رنگی
رنگ‌ها باید soft, muted, cozy باشند
فضا باید لطیف، گرم و آرام باشد
از رنگ‌های جیغ و اشباع بالا پرهیز شود
رنگ‌های تند فقط به‌صورت accent محدود استفاده شوند
5) نورپردازی ثابت

نور یکی از عناصر اصلی یکدستی پروژه است.

ویژگی نور:
نور باید عمق‌دار، نرم و کنترل‌شده باشد
حس کلی باید cozy و cinematic بماند
پرهیز:
نور تخت و بدون عمق
نور خیلی سخت و تند
نور بیش‌ازحد فانتزی، نئونی یا RGB مگر در موارد خاص و آگاهانه
6) نوع رندر و کیفیت خروجی

سبک خروجی باید:

Stylized 3D / 2.5D game art
Polished
دارای soft shadows
دارای clean edges
با ترکیب‌بندی خوانا
Cinematic but not overly dramatic
مناسب mobile game background
نباید شبیه این‌ها باشد:
رندر معماری خشک
تصویر فلت و بی‌عمق
نقاشی کودکانه
کارتون اغراق‌شده
واقع‌گرایی سنگین
اتاق‌های شلوغ Pinterest-style
7) قواعد چیدمان

در همه فضاها:

یک نقطه کانونی اصلی وجود داشته باشد
بقیه عناصر در خدمت آن باشند
اشیاء با فاصله مناسب چیده شوند
فضای خالی و فضای عبور کافی وجود داشته باشد
ترکیب‌بندی باید برای بازی مناسب باشد، نه فقط دکور
حس چیدمان:
طراحی‌شده
قابل‌فهم
خوانا
interactable
8) هویت سنی و فرهنگی

فضا باید حس مربوط به نوجوان امروزی را بدهد:

مدرن
مرتب
کمی cute
قابل‌باور
نه خیلی لوکس
نه خیلی بچه‌گانه
نکته مهم:

لازم نیست در همه صحنه‌ها عناصر واضح ایرانی وجود داشته باشد.
ایرانی بودن بهتر است از طریق حس فضا و واقع‌پذیری منتقل شود، نه با نمادهای مستقیم و کلیشه‌ای.

9) UI و Game Feel

محیط باید برای استفاده در صحنه بازی مناسب باشد:

جا برای UI داشته باشد
مرکز تصویر بیش‌ازحد شلوغ نباشد
اشیاء اصلی خوانا باشند
ساختار صحنه برای انتخاب/کلیک منطقی باشد
حس interactable بودن حفظ شود
10) مواردی که باید همیشه پرهیز شوند
نمایش فضا به‌صورت cutaway room
نمایش اتاق‌های کناری
شلوغی زیاد
واقع‌گرایی خیلی سنگین
کودکانه شدن استایل
استفاده زیاد از متن روی دیوار
عناصر تزئینی بی‌دلیل
رنگ‌های تند و زننده
قاب‌بندی شبیه رندر معماری
حس دکوراسیون صرف
