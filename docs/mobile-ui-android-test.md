## دستگاه و نسخه

- گوشی متصل: Samsung `SM-S731B`، Android 16 / API 36، شناسهٔ ADB برابر `R5CYA0PT8XJ`.
- نمایشگر: `1080×2340`؛ اجرای بازی افقی با تصویر ثبت‌شدهٔ `2340×1080`.
- APK تازه از سورس فعلی با Godot 4.7.2 و preset Android ساخته شد: `SourceProject/HooshUp-debug-install.apk`.
- SHA256: `54A7B9221B7B9B2AFA486B9BBC01C2BD8152997BB754578F135EF8A37174D200`.
- نصب `adb install -r` با پاسخ `Success` انجام شد؛ دادهٔ نسخهٔ قبلی عمداً حذف نشد.
- نام واقعی بسته در همین APK برابر `com.example.noname` و activity قابل اجرا `com.godot.game.GodotAppLauncher` است.

## ایرادهای باقی‌مانده

1. PopupMenu با `LAYOUT_DIRECTION_LTR` و جهت متن RTL، ردیف فارسی را راست‌چین نمی‌کند. این مورد در آزمون headless هندسه قابل تشخیص نبود؛ اصلاح نمایش Popup و بررسی دوبارهٔ گوشی لازم است.
2. `scripts/secure_save_store.gd:132` فراخوانی `KeyGenParameterSpecBuilder.Builder(...)` را انجام می‌دهد؛ Android خطای `Nonexistent function 'Builder' in base 'JavaClass'` می‌دهد. اجرای UI ادامه دارد اما ذخیره‌سازی پایدار تأیید نشده است و نباید سالم فرض شود. این ایراد خارج از تغییرهای UI این دو مرحله است.
3. preset هنوز `package/unique_name="com.example.$genname"` دارد؛ نام فارسی برنامه در Export به `com.example.noname` تبدیل شده است. مقدار ثابت `com.example.hooshup` در اسکریپت نصب و راهنمای قبلی با این APK منطبق نیست؛ به همین دلیل نصب این آزمون با نام واقعی بسته انجام شد. نام بسته و اسکریپت نصب باید هماهنگ شوند؛ تغییر هویت بسته نیازمند تصمیم دربارهٔ انتقال دادهٔ نسخهٔ نصب‌شده است.

تنظیم `1280×720/keep` همچنان نوارهای سیاه طرفین دارد؛ تغییر آن متعلق به مرحلهٔ بعدی مهاجرت است. این آزمون تأیید نمایش و لمس انتخاب‌گر روی همین گوشی است و آزمون کامل همهٔ مأموریت‌ها، حفظ پیشرفت پس از بستن برنامه یا همهٔ مدل‌های Android نیست.
